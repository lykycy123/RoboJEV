02 / METHOD

A visible decision loop.

The simulator provides measurements. JEV chooses an intent, then chooses motion. A Cartesian controller executes and measures the result.

OBSERVE

Measured state

Object pose, TCP, finger contacts, target geometry and recent actions.

→
JEV · STAGE 1

Select intent

A task-conditioned choice distribution over the immediate objective.

→
JEV · STAGE 2

Select action

X, Y, Z and gripper choices, conditioned on the selected intent.

→
EXECUTE

Contact physics

1 cm translation, Jacobian IK and MuJoCo. No object teleportation.

What this demonstrates
Closed-loop, task-conditioned control from privileged simulator state, with independent physical evaluation.

What remains limited
No visual perception, real-robot deployment, free-base stacking, or general-purpose motion planning. API waits pause simulation.
